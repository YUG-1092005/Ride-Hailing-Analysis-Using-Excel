# 🚖 Ride-Hailing Analysis Using Excel

## 📌 Project Overview
This project analyzes **ride-hailing platform data** to uncover **business-critical insights** related to bookings, cancellations, revenue loss, and operational efficiency.

The objective is to simulate a **real-world Data Analyst case study**, focusing not only on metrics but on **actionable insights that matter to CEOs, Product Managers, and Operations teams**.

The entire analysis is built using **Microsoft Excel**, leveraging pivot tables, calculated fields, KPI cards, and executive-style dashboards.

---

## 🎯 Business Objectives
- Analyze **overall demand and booking trends**
- Identify **revenue leakage** caused by cancellations and incomplete rides
- Compare **customer vs driver behavior**
- Detect **peak hours, weekend trends, and high-risk zones**
- Present insights in a **CEO-ready dashboard format**

---

## 🧾 Dataset Description
- The dataset is sourced from **Kaggle**.
- Ride-hailing platforms such as **Ola and Uber** face operational challenges due to frequent ride cancellations by customers and drivers.
- This dataset captures **booking-level information for the month of July**, highlighting interactions between customers, drivers, and vehicle types.
- It is designed to help analysts understand **booking patterns, cancellation reasons, and service efficiency**.

🔗 **Dataset Link:**  
https://www.kaggle.com/datasets/hetmengar/ola-and-uber-ride-booking-and-cancellation-data

## 🔑 Key KPIs

### 🔵 Primary KPIs
- **Total Bookings**
- **Successful Rides**
- **Completion Rate**
- **Cancellation Rate**
- **Gross Merchandise Value (GMV)**

### 🟠 Secondary KPIs
- **Customer Cancellation Rate**
- **Driver Cancellation Rate**
- **Revenue Loss by Customers**
- **Revenue Loss by Drivers**
- **Incomplete Ride Percentage**

> 📌 Multiple supporting KPIs are used to strengthen insights and executive decision-making which can be seen in report.

## 📊 Dashboard Highlights

- **Time-based analysis** (Peak hours, weekends vs weekdays)
